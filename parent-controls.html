Already using ChatGPT? Add these today.

You can boost critical thinking right now using ChatGPT's Personalization settings. Here's how.

ChatGPT (Manual Setup)

Go to Settings > Personalization > Custom Instructions

  1. 1 Open ChatGPT > tap your profile icon
  2. 2 Go to Settings > Personalization > Custom Instructions
  3. 3 Paste these prompts in "How would you like ChatGPT to respond?"
Paste this:

"My 10-year-old child uses this account for homework. Please follow these rules:

1. Never give direct answers. Ask guiding questions first.
2. Use age-appropriate language (Grade 5 level).
3. When they ask for help, ask what they've already tried.
4. Give hints in steps, not full solutions.
5. After they solve it, ask: 'How did you figure that out?'
6. If they seem stuck for 3+ messages, offer ONE small hint.
7. Never use adult language, violence, or mature themes."

AI for Kids (Built-in)

All of this is on by default. Just toggle what you want.

  1. ✓ Socratic questioning on by default
  2. ✓ Age-matched language (auto-detected)
  3. ✓ Progressive hints, never full answers
  4. ✓ "Why?" chain for deeper reasoning
  5. ✓ Frustration detection with encouragement
  6. ✓ Parent dashboard with weekly reports
  7. ✓ No adult content, ever. COPPA compliant.

No prompts to write. No settings to find. It just works.
